# Delta Hotel Booking — Booking Confirmation

Professional Booking Confirmation page with PDF receipt generation (jsPDF).

## Features
- Payment Successful -> Booking Confirmed flow
- Booking ID: 5667465646646564
- Download a professional PDF receipt containing booking details
- Header with company name (left) and user (right) with avatar
- "Go back home" link to /home

## Run locally
1. npm install
2. npm run dev
3. Open http://localhost:5173

## Notes
- The PDF is generated in-browser using jsPDF and downloaded as `receipt-5667465646646564.pdf`.
