ROUTING SYSTEM IMPLEMENTATION (ENHANCED)
=========================================
Complete routing system with role-based access control.

ROUTES:
- / (Landing Page) - Public, accessible to all
- /signin (Sign In Page) - Public, full-page login form
- /signup (Sign Up Page) - Public, full-page registration form
- /rooms (Public Rooms Page) - Public, browse rooms without login
- /dashboard (Customer Dashboard) - Protected, requires authentication
- /admin/* (Admin Dashboard) - Protected, requires admin role

ROLE-BASED ROUTING:
- Admin login → automatic redirect to /admin
- Customer login → automatic redirect to /dashboard
- Home icon navigation based on user role:
  * Admin → /admin (from landing page home icon)
  * Customer → /dashboard (from landing page home icon)
  * Admin navbar home icon → / (landing page)

PROTECTION:
- ProtectedRoute component wraps protected routes
- Access denied messages for unauthorized access
- Conditional navbar rendering based on route
- Session persistence across page reloads
