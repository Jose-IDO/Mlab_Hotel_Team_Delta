HOW TO USE THESE CREDENTIALS
============================

1. ADMIN LOGIN:
   - Click "Sign In" in the navigation bar
   - Enter: admin@deltahotel.com
   - Enter: admin123
   - Click "Sign In"
   - You will be automatically redirected to the admin dashboard (/admin)
   - Home icon in admin navbar returns to landing page
   - Your username will appear in the navbar with logout button

2. CUSTOMER LOGIN:
   - Click "Sign In" in the navigation bar
   - Enter: customer@deltahotel.com
   - Enter: customer123
   - Click "Sign In"
   - You will be automatically redirected to customer dashboard (/dashboard)
   - Home icon on landing page takes you to your dashboard
   - Your username will appear in the navbar with South African flag and logout button

3. BROWSING WITHOUT LOGIN:
   - Click "Rooms" button on landing page to browse available rooms
   - You will see the /rooms page with Sign In and Sign Up buttons
   - Login required to make bookings

4. CREATE NEW USER:
   - Click "Sign Up" in the navigation bar
   - Enter your name, email, and password (min 8 chars, 1 uppercase, 1 number)
   - Click "Sign Up"
   - You will be automatically logged in as a customer
   - Redirected to your customer dashboard

IMPORTANT NOTES
===============

- All users are automatically created when the app starts
- Admin user is seeded automatically
- Customer users need to be created through signup
- Passwords are stored in plain text (development only)
- All data is stored in localStorage (browser only)

SECURITY WARNING
================

These credentials are for development and testing purposes only.
In a production environment, passwords would be hashed and stored
securely in a database with proper authentication.

TROUBLESHOOTING
===============

If you cannot login:
1. Make sure you're using the exact email and password
2. Check for typos in the credentials
3. Try refreshing the page
4. Clear browser localStorage and try again
5. Make sure the authentication system is working

If admin dashboard is not accessible:
1. Make sure you're logged in with admin credentials
2. Check that the user role is "admin"
3. Try logging out and logging back in
4. Clear browser cache and localStorage

For any issues, check the browser console for error messages.
