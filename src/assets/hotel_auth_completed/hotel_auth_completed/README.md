# Hotel Auth UI (Frontend)

This project contains a frontend-only authentication UI using React + TypeScript + Vite + Tailwind CSS + Redux Toolkit.

Features:
- Sign Up and Sign In pages with 50/50 split layout (image + form)
- Reusable components: Input, Button, GoogleButton
- Redux Toolkit for form state and validation
- Hotel background image at `src/assets/hotel-bg.jpg` (replace with your preferred image)
- Mock Google OAuth buttons (UI only)
- Routing between /signup and /signin

## Run locally
1. unzip the project
2. run `npm install`
3. run `npm run dev`
4. open http://localhost:5173

To change the left background image, replace `src/assets/hotel-bg.jpg` with your own image.
